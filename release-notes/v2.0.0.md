## Pico Dashboard 2.0

- **Neue Oberfläche** im dunklen Design mit Live-Anzeige der Fader
- **Firmware wird automatisch verwaltet:** Die App erkennt das Dashboard, spielt Updates selbst auf – kein Dateien-Kopieren mehr
- **Neuen Pico einrichten:** CircuitPython wird automatisch heruntergeladen und installiert (BOOTSEL-Modus)
- **Automatische Updates** der App über GitHub
- **Dashboard:** Start-Animation, Lautstärke-Anzeige beim Bewegen eines Faders, Bildschirmschoner
- Pin-Belegung und Anzeige-Einstellungen direkt in der App
- Fader 1 und Fader 3 standardmäßig getauscht (Fader 1 = GP28, Fader 3 = GP26)
