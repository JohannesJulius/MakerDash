## MakerDash 2.1.0

**Pico Dashboard heißt jetzt MakerDash.** Einstellungen und Autostart werden automatisch übernommen,
die alte Installation wird beim Update entfernt.

- **Neuer Bildschirmschoner:** Statt das Display abzuschalten, wandert ein gedimmtes MakerDash-Logo
  mit wippenden Mini-Fadern über den Bildschirm
- **Schnelleres Menü am Dashboard:** Schriften werden beim Start vorgeladen, Texte als ein Bild
  gezeichnet und das Display mit 400 kHz angesprochen
- **Neue Geräte-Grafik** in der App nach der Frontplatten-Zeichnung (Display oben, drei Fader,
  Drehgeber unten)
- Firmware 2.1.0 (wird von der App automatisch aufgespielt)
